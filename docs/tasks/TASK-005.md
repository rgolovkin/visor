# TASK-005: Виджет «Батарея» (IOKit)

## Бизнес-цель
Видеть заряд и состояние питания Mac, не заглядывая в меню-бар; получать заметный сигнал при подключении зарядки и низком заряде.

## Зависимости
TASK-001, TASK-002. `id: battery`.

## Описание
Источник — IOKit Power Sources (`IOPSCopyPowerSourcesInfo`, `IOPSNotificationCreateRunLoopSource` — **событийная подписка, без опроса**). Дополнительно (если доступно без приватных API) — данные AppleSmartBattery из IORegistry для здоровья/циклов, читаются только при открытии expanded.

**Compact (peek)**: `isActive = true` только в «событийных» ситуациях: (а) недавно подключено/отключено питание — показывается 5 секунд; (б) заряд ≤ порога низкого заряда (по умолчанию 20%) при работе от батареи — **постоянно**, пока не подключат питание, не поднимется выше порога + 2% или пользователь не нажмёт «скрыть» (Q2); (в) достигнут 100% при зарядке — 5 секунд (по настройке). Содержимое: иконка батареи с заливкой, процент, молния при зарядке; при низком заряде — кнопка «скрыть» (небольшой крестик). Приоритет 80 (ниже таймера 90, см. TASK-001: пока идёт таймер, peek низкого заряда не виден, но виден в expanded).

**Кнопка «скрыть»**: прячет peek низкого заряда до следующего падения, т.е. до момента, пока заряд не поднимется выше порога + 2% или не будет подключено питание и затем снова не упадёт до порога. Исключение: пересечение критического порога (≤ 10%) после скрытия — это новое падение, peek показывается снова один раз.

**Expanded**: крупный индикатор и процент, источник питания («От сети» / «От батареи»), оставшееся время до разрядки/полной зарядки (если система его оценила; иначе «Вычисляется…»/скрыто), состояние «Заряжается / Заряжена / Не заряжается», режим энергосбережения (Low Power Mode, только отображение), опционально: циклы и здоровье батареи (максимальная ёмкость в %) мелким шрифтом. Температура не показывается (Q1).

**Настройки** (`widgets[].settings`): 
- `lowThresholdPercent` (10/15/20/30, по умолчанию 20);
- `showPercentInPeekOnPlug` (true);
- `peekOnFull` (true);
- `showHealthDetails` (true).

**Нет батареи (Mac mini/Studio/iMac)**: виджет показывает «Батарея не обнаружена — Mac работает от сети», не isActive; в настройках виджет остаётся доступным (можно выключить).

## Критерии приёмки (Acceptance Criteria)
- [ ] AC-1: Дано MacBook на батарее, тогда expanded показывает процент в пределах ±1% от значения в меню-баре macOS и статус «От батареи».
- [ ] AC-2: Дано зарядное устройство подключено, тогда ≤ 1 с в peek появляется иконка с молнией и процентом на 5 секунд, затем peek гаснет (если нет других причин).
- [ ] AC-3: Дано зарядка отключена, тогда аналогичный 5-секундный peek с новым статусом.
- [ ] AC-4: Дано заряд падает до порога при работе от батареи, тогда peek включается (цвет предупреждения) и остаётся, пока питание не подключено, заряд не поднялся выше порога + 2% (гистерезис против дребезга) или пользователь не нажал «скрыть».
- [ ] AC-5: Дано заряд ≤ 10% (критический), тогда индикатор красный; peek остаётся без ограничения по времени (до подключения питания, подъёма выше порога + 2% или «скрыть», см. AC-13).
- [ ] AC-6: Дано 100% при подключённом питании, тогда при `peekOnFull` — 5-секундный peek «Заряжена»; повторно не показывается, пока заряд не упадёт ниже 95%.
- [ ] AC-7: Дано Mac без батареи, тогда показывается сообщение «Батарея не обнаружена», виджет не активен и не падает.
- [ ] AC-8: Дано оценка времени недоступна (`kIOPSTimeRemainingUnknown`/идёт расчёт), тогда в UI нет «-1», «0 мин» и т.п.; поле скрыто или «Вычисляется…».
- [ ] AC-9: Дано изменение любого параметра питания (процент, источник, режим), тогда UI обновляется ≤ 2 с без опроса в цикле (проверяется: нет таймеров обновления в виджете).
- [ ] AC-10: Дано виджет выключен, тогда источник событий IOKit снят с run loop и освобождён.
- [ ] AC-11: Дано подключены периферийные устройства (AirPods и др.), тогда они не отображаются (вне scope), и виджет не ломается из-за дополнительных источников в списке Power Sources.
- [ ] AC-12: Дано изменён порог в настройках, тогда новое поведение peek применяется немедленно.
- [ ] AC-13: Дано peek низкого заряда, когда пользователь нажимает «скрыть», тогда peek гаснет и не появляется снова, пока не выполнится условие «следующего падения» (см. выше); при пересечении критического порога 10% после скрытия peek показывается снова. Нажатие «скрыть» не открывает expanded (клик по остальной части peek открывает).

## Нефункциональные требования
- 0% CPU в простое: только run-loop-source на событиях IOKit; пересчёт состояния — на изменение.
- Работа без каких-либо системных разрешений.
- Только публичные API; не использовать приватные ключи, которые могут пропасть между версиями macOS — недоступные поля скрываются, не вызывают ошибку.
- Swift 6: CF-объекты/IOKit-колбэк корректно мостятся на `@MainActor`.

## Граничные случаи
- Несколько источников питания (ИБП на настольном Mac) — показываем внутреннюю батарею, при её отсутствии виджет «не обнаружена».
- Зарядка «медленная/не заряжается» (оптимизированная зарядка, Optimized Battery Charging на 80%) — статус «Не заряжается (оптимизация)», а не «Разряжается».
- Выход из сна: состояние перечитывается.
- Быстрые подключения-отключения кабеля — события коалесцируются (дебаунс ~300 мс), peek не мигает.
- Процент недоступен (nil) — показываем «—».
- Режим энергосбережения включён/выключен вне приложения.
- Состояние «скрыто» не переживает перезапуск приложения (хранится в памяти).

## Не входит в задачу (Out of scope)
- Батареи AirPods, Magic Mouse/Keyboard, iPhone (будущий виджет «устройства»).
- Управление зарядкой (лимит 80%), включение Low Power Mode из приложения.
- Системные уведомления и звуки.
- Графики истории заряда, потребление по приложениям, температура батареи.
- Показ процента батареи в collapsed (Q4).

## Принятые решения
- Q1: Температура и циклы? → Циклы и здоровье — да (в expanded, мелким шрифтом); температура — нет в этой итерации.
- Q2: Peek при низком заряде — постоянный или по времени? → Постоянный (пока на батарее и ниже порога) с кнопкой «скрыть» до следующего падения (AC-13).
- Q3: Порог по умолчанию? → 20%, гистерезис 2%.
- Q4: Показывать процент всегда в collapsed? → Нет (collapsed пуст по принципу TASK-001).

Открытых вопросов нет.
