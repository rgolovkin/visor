# TASK-004: Виджет Таймер (таймер + Pomodoro)

## Бизнес-цель
Быстро запустить обратный отсчёт или Pomodoro-цикл, не отвлекаясь, и видеть остаток времени прямо в чёлке.

## Зависимости
TASK-001, TASK-002. `id: timer`.

## Решение по структуре (зафиксировано)
**Один виджет «Таймер» (`id: timer`) с двумя режимами: «Таймер» и «Pomodoro»** (сегмент-переключатель в expanded). Обоснование: общий движок отсчёта, одно место и один приоритет в peek, один слот в списке виджетов; запрет одновременной работы двух отсчётов (Q1).

## Описание
Общий движок: состояние `idle | running | paused | finished`, хранит не «оставшиеся секунды в цикле тиков», а **целевую абсолютную метку времени `endsAt`** (монотонное время/`Date`) — остаток вычисляется при отрисовке. Это даёт корректность после сна и без накопления дрейфа.

### Режим «Таймер»
- Expanded: ввод длительности (пресеты 1/5/10/15/30 мин + ручной ввод ЧЧ:ММ:СС), кнопки Старт/Пауза/Сброс, крупный остаток, кольцо прогресса.
- По окончании: звук (системный), ощутимая подсветка в peek, состояние `finished` до подтверждения («Готово» / «+1 мин»).

### Режим «Pomodoro»
- Цикл: работа (25 мин) → короткий перерыв (5 мин), после 4 рабочих сессий — длинный перерыв (15 мин). Все длительности и количество сессий настраиваются.
- Expanded: текущая фаза, остаток, счётчик сессий (●●○○), Старт/Пауза/Пропустить фазу/Сброс.
- Автопереход к следующей фазе: настройка `autoStartNext` (по умолчанию false: ждём нажатия).
- Статистика (сегодня завершено сессий) — только счётчик за текущий день, хранится локально.

### Peek
`isActive = true`, пока отсчёт `running`, `paused` или `finished`. Compact: иконка (таймер/томат), остаток `мм:сс`, мини-кольцо; на паузе — приглушённо с иконкой паузы; в `finished` — выделение и «Готово». Приоритет 90 (самый высокий). Клик по peek открывает expanded. Запускать таймер можно только из expanded (Q6).

### Настройки (`widgets[].settings`)
- `pomodoro.workMinutes` (25), `pomodoro.shortBreakMinutes` (5), `pomodoro.longBreakMinutes` (15), `pomodoro.sessionsBeforeLongBreak` (4), `pomodoro.autoStartNext` (false);
- `sound`: имя системного звука или «выкл» (по умолчанию включён, звук «Glass», Q4);
- `notifyOnFinish`: системное уведомление (UNUserNotificationCenter), запрос разрешения лениво при первом включении опции (по умолчанию false, Q3);
- `lastTimerSeconds` — запоминание последней длительности таймера.

### Обновление
Секундный тик (1 Гц) работает только пока отсчёт в состоянии `running` (в этом состоянии виджет всегда isActive, поэтому peek или expanded показывают остаток). В `paused`, `finished` и `idle` тиков нет. Независимо от тика ставится одноразовая задача на момент `endsAt`: она срабатывает по окончании отсчёта, в том числе если панель свёрнута, и пересчитывается после выхода из сна.

### Персистентность
Состояние отсчёта (режим, фаза, `endsAt`/остаток, номер сессии) сохраняется в `~/Library/Application Support/NotchApp/data/timer.json` (JSON, ISO-8601, платформонезависимо). При перезапуске приложения активный отсчёт восстанавливается (Q2).

## Критерии приёмки (Acceptance Criteria)
- [ ] AC-1: Дано режим «Таймер», когда пользователь задаёт 5:00 и нажимает «Старт», тогда в peek сразу появляется остаток, значение уменьшается каждую секунду.
- [ ] AC-2: Дано таймер идёт, когда «Пауза», тогда остаток замирает; «Старт» продолжает с замороженного значения; «Сброс» возвращает в idle и убирает peek.
- [ ] AC-3: Дано таймер дошёл до 0, тогда воспроизводится звук (если включён), состояние `finished`, в peek «Готово» остаётся до подтверждения; действие «+1 мин» запускает новый отсчёт на 60 с.
- [ ] AC-4: Дано таймер запущен, когда Mac засыпает на 10 минут и просыпается, тогда остаток корректен (учитывает реальное время); если срок истёк во сне — немедленно `finished` (звук один раз, без залпа).
- [ ] AC-5: Дано точность, тогда за 10 минут отклонение от реального времени ≤ 1 с (расчёт от `endsAt`, а не накопление тиков).
- [ ] AC-6: Дано режим «Pomodoro», когда пользователь нажимает «Старт», тогда начинается рабочая фаза 25 мин; по её окончании — сигнал и переход к короткому перерыву (старт по `autoStartNext`).
- [ ] AC-7: Дано завершена 4-я рабочая сессия, тогда следующий перерыв — длинный (15 мин), счётчик сессий сбрасывается после него.
- [ ] AC-8: Дано Pomodoro, когда «Пропустить», тогда выполняется переход к следующей фазе; пропущенная рабочая сессия не засчитывается в статистику.
- [ ] AC-9: Дано изменены длительности в настройках во время идущей фазы, тогда текущая фаза не меняется; новые значения применяются со следующей.
- [ ] AC-10: Дано запущен один режим, когда пользователь пытается запустить другой, тогда показывается подтверждение «Остановить текущий?»; одновременно работает только один отсчёт.
- [ ] AC-11: Дано приложение перезапущено при идущем отсчёте, тогда отсчёт восстановлен с корректным остатком; если срок истёк менее 5 минут назад — состояние `finished` (звук воспроизводится один раз); если более 5 минут назад — тихо переходит в idle без звука (Q2).
- [ ] AC-12: Дано ввод длительности вне диапазона (0, отрицательное, > 99:59:59, нечисловое), тогда ввод отклоняется с подсказкой, Старт недоступен.
- [ ] AC-13: Дано виджет idle, тогда он не isActive, нет таймеров и нагрузки (0% CPU); при выключении виджета во время отсчёта — отсчёт останавливается, состояние сбрасывается после подтверждения.
- [ ] AC-14: Дано `notifyOnFinish` включён, тогда системное уведомление приходит по окончании; при отказе в разрешении опция показывает пояснение и выключается.
- [ ] AC-15: Дано разные локали/часовые пояса и смена системного времени вручную, тогда отсчёт не ломается (используется монотонное время для вычисления длительности).

## Нефункциональные требования
- Во время отсчёта CPU < 1% (обновление только text/кольца, без перерисовки всей панели); в idle ~0%.
- Анимация кольца не создаёт 60-fps таймер: изменение прогресса — раз в секунду с implicit-анимацией.
- Звук — только системные (`NSSound`), без ресурсов в бандле.
- Файл timer.json пишется атомарно и только при смене состояния (старт/пауза/сброс/фаза), не каждую секунду.

## Граничные случаи
- Часы переведены вручную / NTP-коррекция во время отсчёта.
- Нажатие «Старт» дважды подряд; быстрое «Старт-Пауза-Старт».
- Завершение во время закрытой крышки/сна — звук проигрывается при пробуждении, а не в тишине (см. AC-4).
- Режим «Не беспокоить»/Focus — уведомление и звук подчиняются системным правилам.
- Длительность 1 с, очень длинные (99 ч).
- Выход из приложения (Quit) при идущем отсчёте — состояние сохранено.
- Повреждённый timer.json — игнорируется, виджет стартует idle.

## Не входит в задачу (Out of scope)
- Секундомер (прямой отсчёт), несколько параллельных таймеров, именованные таймеры.
- Подробная статистика/история Pomodoro, интеграция с задачами.
- Синхронизация между устройствами, интеграция с Focus-режимами macOS.
- Горячие клавиши и Siri/Shortcuts.
- Запуск таймера из peek или меню-бара.

## Принятые решения
- Q1: Один виджет с двумя режимами или два? → Один виджет «Таймер» с режимами (подтверждено). Одновременно только один отсчёт.
- Q2: Восстанавливать отсчёт после перезапуска? → Да; если срок истёк более 5 минут назад — тихо в idle без звука (AC-11).
- Q3: Системные уведомления? → По умолчанию выкл. (звук + peek), опция в настройках.
- Q4: Звук по умолчанию? → Включён, системный «Glass».
- Q5: Длительности Pomodoro по умолчанию? → 25/5/15, длинный перерыв после 4 сессий.
- Q6: Запуск «на лету» из peek/меню-бара? → Нет, только из expanded.

Открытых вопросов нет.
